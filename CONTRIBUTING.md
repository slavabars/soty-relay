# Участие в разработке релея Soty

**Русский** · [English](CONTRIBUTING.en.md)

`dtm_host` — операторский релей и трекер пиров. Изменения здесь влияют на каждый релей в федерации, поэтому их проверяют внимательно.

## Перед началом

- Прочитайте `docs/threat_model.md` перед изменением протокола или хранилища.
- Для нетривиального изменения сначала откройте issue.
- Проблемы безопасности — в `SECURITY.md`, **никогда** в публичный issue.

## Разработка

`dtm_host` импортирует пакет `dtm_app` с общим кодом конвертов и криптографии, поэтому репозитории должны лежать рядом:

```text
workspace/
  app-src/     # https://github.com/slavabars/soty-app
  host/        # этот репозиторий
```

```bash
export PATH="$HOME/development/flutter/bin:$PATH"

cd host
flutter pub get
dart analyze
flutter test --no-pub
```

## Релей для OpenWrt (Go)

`relay-owrt/` — вторая реализация протокола на Go. Она обязана совпадать с `dtm_host` по wire-формату, поэтому изменения протокола проверяются в обеих реализациях.

```bash
cd relay-owrt
go test ./...
go vet ./...
VERSION=X.Y.Z+N ./openwrt/build-bundle.sh
cd ../.. && scripts/verify_owrt_bundle.sh build-artifacts/dtm_relay-X.Y.Z+N-ipk.tar.gz
```

- Golden-вектор `internal/wire/testdata/vector.json` создаётся `host/tool/gen_wire_vector.dart`; не подгоняйте его под Go-код.
- Все архитектуры из `openwrt/arches.txt` должны собираться; `GOMIPS=softfloat` обязателен для mips.
- Пакет `.ipk` для OpenWrt 24.10+ — gzip-tar, не `ar`.
- Тест на живом роутере начинается с проверенного бекапа (`sysupgrade -b`, overlay, `/etc`, пакеты) и заканчивается откатом к исходным `uci export`/`opkg list-installed`.

## Правила

- **Сначала тест**, включая враждебные пути: слишком большие фреймы, неверные подписи, повторные конверты, поддельные узлы федерации, флуд подписок.
- **Лимиты применяются до выделения памяти.** Не добавляйте неограниченные списки, буферы и кэши.
- **Никогда не удаляйте `host.db`** в коде, скриптах и доках: там `host_state.ed_seed` и все пины клиентов.
- **Никогда не логируйте** содержимое конвертов, ключи и seeds.
- Типы wire-сообщений остаются UPPERCASE, а handshake — обратно совместимым: релеи обновляются по одному.
- Один логический change на pull request.
- Не переносите строки в доках, шаблонах и commit messages вручную: один абзац или пункт списка — одна строка исходника.

## Pull requests

- Опишите влияние на протокол и порядок раскатки.
- Укажите, что проверили (`dart analyze`, `flutter test`, `host_probe.py`).
- CI подтягивает `soty-app` рядом с этим репозиторием и должен быть зелёным.
- Отправляя код, вы соглашаетесь на лицензию AGPL-3.0.
